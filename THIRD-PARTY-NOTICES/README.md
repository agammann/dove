# Dependency notices

Copies of license and notice files supplied by installed locked Python and npm dependencies. The index includes runtime and development packages. Docker base images retain their distribution notices within the images. These licenses do not assign a license to Dove's original source. Regenerate using the locked environments and scripts/collect_notices.py.

## Link compatibility

`README.ijg` is an unmodified copy of the bundled pypdfium2 libjpeg-turbo IJG notice. It preserves the relative link used by the upstream libjpeg-turbo license document.

Some upstream repository URLs embedded in the original Vite notices returned HTTP 404 when checked on September 13, 2026 UTC. The original copyright and license notices are preserved. Package information remains available through the [commondir package metadata](https://registry.npmjs.org/commondir/latest) and [tsconfck package metadata](https://registry.npmjs.org/tsconfck/latest). These registry records are alternate references, not replacement contributor histories.
