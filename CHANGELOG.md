# Changelog

## 1.0.0

Dove v1 defines a single-device browser product with source-linked document review, human decisions, invoice and package downloads, exact version approval and complete backup restoration. Added a model-free fictional quickstart, MIT license, upgrade/recovery guide and source-release packaging.

Applied available sharp and source-map-js dependency patches while retaining the existing saved-work and backup formats. Native landing-tool checks run against genuine browser APIs; device downloads/generation and hosted first responses are recorded separately. GPT-5.4 remains the hosted default. The lower-cost mini option now reminds visitors to calculate payment dates manually after a checked response omitted the implied date.

The separately runnable Python example retains simulated adapters by default. No automatic synchronization, email delivery, payment tracking, OCR or accounting integration is added.
