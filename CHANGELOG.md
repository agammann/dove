# Changelog

## 2.0.0

The complete source delivery now includes the guarded, fresh-only PostgreSQL 18 Python sample, Python 3.15 Docker runtime and existing TypeScript 7 frontend work. This is a breaking installation change from the PostgreSQL 17 sample in 1.0.0. Existing databases and matching object stores must be preserved under their previous checkout pending a separately reviewed migration; initialization is not a migration. The exact release commit now requires the existing synthetic PostgreSQL upgrade/rollback rehearsal as well as fresh-install and credential guards before publication.

Browser product, saved-work and backup formats remain version 1. No document, approval, provider, storage, model or landing-tool behavior changes. Apply the Vite 8.3.7/Rolldown 1.2.19 and separate frontend Vite 6.4.6 development-server patches for GHSA-p4f5-76q4-ffq7. Locked audits reported zero before those patches; the maintainer advisory independently establishes the affected versions, specifically when the development server is exposed to a network. The default scripts bind loopback; this is not a claim of deployed Worker compromise.

Clarify each frontend's supported Node ranges, correct current sample labels and documentation punctuation, and distinguish optional visitor-funded browser analysis from the separate Python providers. Preserve historical verification and the immutable 1.0.0 release.

## 1.0.0

Dove v1 defines a single-device browser product with source-linked document review, human decisions, invoice and package downloads, exact version approval and complete backup restoration. Added a model-free fictional quickstart, MIT license, upgrade/recovery guide and source-release packaging.

Applied available sharp and source-map-js dependency patches while retaining the existing saved-work and backup formats. Native landing-tool checks run against genuine browser APIs; device downloads/generation and hosted first responses are recorded separately. GPT-5.4 remains the hosted default. The lower-cost mini option now reminds visitors to calculate payment dates manually after a checked response omitted the implied date.

The separately runnable Python example retains simulated adapters by default. No automatic synchronization, email delivery, payment tracking, OCR or accounting integration is added.
